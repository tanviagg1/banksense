# BankSense — Customer Segmentation & Product Recommender

## Purpose
An end-to-end ML project that clusters bank customers by financial behavior and recommends the right financial product to each segment. Built as a learning project covering all core ML concepts.

## Stack
- Python 3.10+
- pandas — data manipulation
- numpy — numerical operations
- scikit-learn — preprocessing, PCA, KMeans, evaluation
- matplotlib + seaborn — visualization
- jupyter — notebooks for exploration

## Folder Structure
```
banksense/
├── notebooks/
│   ├── 01_data_generation.ipynb    # generate + explore synthetic data, intro to pandas
│   ├── 02_eda.ipynb                # distributions, correlations, outliers
│   ├── 03_preprocessing.ipynb      # scaling, encoding, missing values
│   ├── 04_pca.ipynb                # dimensionality reduction + visualization
│   ├── 05_clustering.ipynb         # KMeans, elbow method, silhouette score
│   └── 06_analysis.ipynb           # cluster profiling + product recommender
├── src/
│   ├── data_generator.py           # generates synthetic customer data
│   └── recommender.py              # maps clusters to product recommendations
├── data/                           # auto-created by notebook 01
├── requirements.txt
└── CLAUDE.md
```

## How to Run
```bash
cd banksense
pip install -r requirements.txt
jupyter notebook
```
Open notebooks in order: 01 → 06.

## Data
Synthetic banking data generated by `src/data_generator.py`. Features:
- age, annual_income, monthly_spending, savings_balance
- credit_score, num_existing_products, months_as_customer, loan_amount

## Key Concepts Covered
1. pandas DataFrames — selection, filtering, groupby
2. EDA — distributions, correlations, outlier detection
3. Preprocessing — StandardScaler, encoding, missing value imputation
4. PCA — dimensionality reduction, explained variance
5. KMeans clustering — elbow method, silhouette score
6. Cluster analysis — profiling, naming segments
7. Rule-based recommendation — mapping patterns to products
